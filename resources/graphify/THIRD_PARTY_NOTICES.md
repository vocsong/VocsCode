# Third-party notices for the Vocs Code Graphify runtime

- **Graphify** (`graphifyy` 0.9.115) — Apache-2.0 and separately identified MIT material. See `vendor/graphifyy-0.9.115.dist-info/licenses/` for upstream `LICENSE`, `LICENSE-MIT`, and `NOTICE`. [Source release](https://github.com/Graphify-Labs/graphify/tree/v0.9.115) · [PyPI distribution](https://pypi.org/project/graphifyy/0.9.115/).
- **CPython 3.12.16** — see `python/LICENSE.txt` (Windows) or `python/lib/python3.12/LICENSE.txt` (Linux/macOS). This is a reduced, relocatable distribution from [Python Build Standalone release 20261110](https://github.com/astral-sh/python-build-standalone/releases/tag/20261110). The installer omits development tooling and renames the Unix executable; it does not patch upstream CPython or Graphify code.
- **Python Build Standalone and its bundled libraries** — see the accompanying `licenses/LICENSE*` files, taken from [release source tree `9244801782b78e4c4afc5c82a4524aa2101d3298`](https://github.com/astral-sh/python-build-standalone/tree/9244801782b78e4c4afc5c82a4524aa2101d3298). Not every component is present on every target. See the same tree's [`pythonbuild/downloads.py`](https://github.com/astral-sh/python-build-standalone/blob/9244801782b78e4c4afc5c82a4524aa2101d3298/pythonbuild/downloads.py) for exact source archive versions, URLs and hashes. Windows includes the app-local Microsoft Visual C++ runtime from the standalone distribution; see the CPython license's Windows binary redistribution section.
- **Python wheel dependencies** — the unmodified notices and licenses are retained in `vendor/*.dist-info/` alongside the packages. Each `METADATA` gives its name, version and upstream project links. `tree-sitter-groovy` 0.1.2 declares MIT in wheel metadata but ships no separate license file; see `licenses/tree-sitter-groovy-0.1.2-MIT.txt` for the terms and attribution.
- **NumPy 2.2.6 and bundled native math libraries** — see `vendor/numpy-2.2.6.dist-info/LICENSE.txt` for the target's NumPy, OpenBLAS and applicable GCC runtime notices, including the libquadmath terms where bundled. [NumPy release and source sdist](https://pypi.org/project/numpy/2.2.6/#files) · [NumPy release build sources](https://github.com/numpy/numpy/tree/v2.2.6) · [upstream SciPy OpenBLAS build recipes](https://github.com/MacPython/openblas-libs). Bundled shared libraries remain standalone files in `vendor/` rather than being linked to Vocs Code or written to system library directories.
