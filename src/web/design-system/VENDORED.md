The variable fonts are redistributed under the SIL Open Font License (see `fonts/OFL-*.txt`).

Refresh from a trusted checkout of `vocsong/vocs.io`: run `node scripts/sync-design-system.mjs --vendor <scratch-dir>` **from that checkout**, then copy `vocs-ui.css`, `fonts.css`, `version.json`, `fonts/` and `favicons/code.svg` here. The generated Worker TypeScript and other products' favicons aren't used by the Vite site. Don't edit this copy; put Code dashboard rules in `../web.css`.
